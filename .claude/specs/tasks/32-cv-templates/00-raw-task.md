Task 32. Create CV templates

Description.
We want to give user the possibility to select the visual style of the exported optimized cv.

At first we want to provide 3 clean templates that user will be able to choose from.
For MVP, build 3 html templates:
1.	ATS-Optimized (single column, plain) — recommended default
2.	Modern (subtle accents, still ATS-safe)
3.	Executive (slightly more elegant, for senior roles)
You can use the provided images as inspiration.

We must provide also the option to preview template (filled with some sample data).

Allow user to select one of the 3 templates. By default template number 1 should be selected and used for the exported cv in pdf and docx.

The exported cv should reflect the visual style of the selected template.
