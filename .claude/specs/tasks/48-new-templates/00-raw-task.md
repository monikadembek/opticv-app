Task 48: Add new templates

Description:

1. Remove current templates: default and corporate and rename 'Modern' to sth else.

2. Add new templates: classic, moderm, corporate, minimal, impact. Mockups are provided in OpiCV Resume Templates.html file in ui folder.

3. Add accentColor parameter that user will be able to select in export-footer and that color will be applied to the selected template as an accent color. Allow the following colors: emerald, blue, purple, red, or teal.

4. In export-footer component next to the templates select add button (icon button from PrimeNg) that will open dialog and display the folllowing text:

"All templates are ATS friendly.
All templates follow ATS best practices:
- Single-column layout — no sidebars or tables
- Standard section headings (Summary, Experience, Education, Skills, Languages)
- Clean heading hierarchy (h1 → h2)
- No images, icons, or graphics — pure text
- Standard fonts (Lato + Montserrat)

Use the Accent Color tweak (in the tweaks panel) to try different accent colors — emerald, blue, purple, red, or teal — which updates the Modern, Corporate, and Impact templates dynamically."
