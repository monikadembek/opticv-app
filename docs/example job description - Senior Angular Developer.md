Opis oferty
We are looking for an experienced Frontend Angular Developer to join an international project focused on building an integrated SDI & PPM solution.
The solution will enable the client to collect information about ongoing projects from multiple business units within one centralized and standardized system used for reporting purposes. The platform will support business processes allowing users to submit, review, approve, or reject project data, as well as send automated reminders when updates are required.
The main objective of the project is to ensure centralized and standardized data collection while following best practices regarding scalability, security, maintainability, and future extensibility.
The solution will be based on Microsoft technologies, including .NET Core and Microsoft Azure on the backend side. The frontend application will be developed in Angular as a modern web application optimized for handling complex business forms and workflows.
